## Overview
This project builds a scalable Python-based data engineering pipeline to process UK Police crime data and prepare a BI-ready reporting dataset for Power BI.

The pipeline follows a Bronze → Silver → Gold architecture to ingest, clean, validate, enrich, aggregate, and export crime data for reporting and analytics.

---

## Police Forces Used
- West Midlands Police
- Thames Valley Police
- Surrey Police
- Cumbria Constabulary

---

## Datasets Used

### Crime Data
Source: https://data.police.uk/data/

Contains:
- Crime category
- Police force
- Location
- Reporting month
- Crime outcomes

### Population Data
Used to calculate population-adjusted crime rates.

### House Price Data
Used as a socioeconomic enrichment dataset.

### IMD Data
Used to provide deprivation indicators and socioeconomic context.
